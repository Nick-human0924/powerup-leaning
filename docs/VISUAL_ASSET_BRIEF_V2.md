# Visual assets V2

目标：家长快速带练与7岁孩子的短时英语表达。保留米白、深绿、柔薄荷和暖橙，改用原创、有纸张与绘画质感的插画。插画为产品装饰，不冒充教材原页。不把真实儿童照片或教材页发给生图模型。

三个独立资产：
1. hero-learning-v2.png：横版，家长与孩子在生活场景里开口交流；人物集中右侧，左侧米白留白供真实HTML文字。预计显示320–900px宽、140–220px高，允许object-fit但不可裁掉脸。
2. parent-guide-v2.png：方形，家长与孩子自然问答，柔薄荷/米白底，显示90–130px，形状与人物容易辨认，无文字。
3. child-practice-v2.png：方形，同一风格的孩子自主说话/听题，暖杏底，显示90–130px，无文字。

统一要求：圆润但不幼稚的现代绘本插画、纸感和柔光、自然手部、清楚面部、没有品牌/水印/可读字母、没有吵闹杂物。小尺寸能辨认真实使用模式，不做空洞线框SVG图标。

字体：主要正文18px，重要按钮17–18px；辅助说明至少14px；极短栏目眉题12px；英语练习问题26–30px；输入框至少16px。保持44–48px触控与375px首屏两个模式入口。教材Unit0/Hello、1–7顺序一致；V3纲要明确标为参考待原页。

门禁：生成→本地检查→产品经理审视（PM_ASSET_REVIEW.md）→合格后接入→浏览器实际截图与字体测量→产品经理最终验收。未经图像检查与门禁不得用临时素材替换。
