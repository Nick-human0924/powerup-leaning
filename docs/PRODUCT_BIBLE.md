# 产品原则

安哲每周3–4次外教课，每次约25分钟；额外复习总预算每周30分钟。家长打开首页1次点击进入3分钟家长/孩子练习，一次只问一题。时间选项2/3/5/10分钟是选题预算，累计时间使用实际练习时长。

信息区：今日推荐与理由、教材来源与课次、两种练习、反馈候选核对、可追溯记录。保留V3米白 #F8F6F0、绿 #116B5B、橙 #EF9866，避免排行榜和虚构测评分数。

三条真相始终分开：资料已收录、确实上过的课次、已确认的表现。没有授课日期不能用导入时间补齐；没有观察证据保持未测。看过提示/答案后复述不能记录独立。ASR失败不能当错误。

原页核对：初始只有V3真实p45/47/49页图，不是九份PDF的完整解析。p49原句请求chocolate，V3 water请求属于扩展练习。其他单元只保留目录参考，不代表知识点已解析。

初步掌握：至少一次家长确认的独立表现。稳定掌握：最近错误/提示之后，在至少2个不同本机日期独立完成。1/3/7天推荐和掌握标签都是产品启发式规则，不是经验证的能力测评。

语音与AI候选必须有原始证据，家长最终确认。录音默认在本机。手机浏览器权限和网络失败时保持文字/手动模式可用。
