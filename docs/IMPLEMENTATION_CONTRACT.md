# Internal integration contract

Core owns src/lib/schema.ts, db.ts, domain.ts, feedback.ts, recommendations.ts, migrations.ts, seed.ts. UI owns src/app/layout.tsx, page.tsx, globals.css and src/components/. Controller owns ingestion.ts, providers.ts, API routes, scripts, public, tests, configuration and docs.

Schema exports TS types and Zod: Material, SourceAsset, SourcePage, Unit, Section, Skill, PracticeTask, LessonSession, PracticeSession, Observation, ParentNote, AudioAsset, ImportJob, Snapshot, snapshotSchema. Snapshot has schema_version='1.0.0' and arrays: materials, assets, pages, units, sections, skills, tasks, lessons, sessions, observations, notes, audio, jobs, audit. Audit entries {id,timestamp,action,entity_id,detail}. Each entity uses prompt fields. IDs strings. Skill has title, type, canonical_expression?, words?, goal, unit_id, source_page_ids, origin, review_status, version, source_evidence, confidence. Page pdf_page_index nullable when unknown, printed_page_number nullable, content_hash?, extracted_text?. ParentNote has id, raw_text, transcript?, media_ref?, transcription_status, consent_status, linked_observation_ids, created_at. Assets storage_ref can be local blob key or '/reference-pages/p49.jpg'.

db.ts exports loadSnapshot():Promise<Snapshot>; mutateSnapshot(fn:(draft:Snapshot)=>void):Promise<Snapshot> atomic serialized read-modify-write with Zod+references validation; mergeBackup(input:unknown):Promise<Snapshot> idempotent merge preserving records; saveBlob(id:string,blob:Blob):Promise<void>; getBlob(id:string):Promise<Blob|undefined>; deleteBlob(id:string):Promise<void>; clearAll():Promise<void>. Initial seed from fetch('/seed.json') private generated reference data; attachments separate IndexedDB table. Snapshot JSON excludes blobs. No silent fallback to volatile memory.

domain.ts exports makeId(prefix?:string):string; mastery(skillId:string,s:Snapshot):{status:string,label:string,reason:string}; recordObservation(s:Snapshot,input:Omit<Observation,'id'|'timestamp'> & {timestamp?:string}):Observation enforces hinted/revealed never independent; generateTasks(skill:Skill):PracticeTask[]. Outcome enum independent,prompted,miss,not_tested,unverified.

recommendations.ts exports recommend(s:Snapshot,minutes:number,now?:Date,unitId?:string):Array<{task:PracticeTask,skill:Skill,reason:string}>. feedback.ts exports proposeFeedback(text:string,s:Snapshot):Array<{skill_id:string,outcome_suggestion:Outcome,source_phrase:string,confidence:number}>; suggestions require parent confirmation, dynamic skill match ambiguity=>unverified. migrations.ts migrateBackup(input:unknown,base?:Snapshot):Snapshot.

Controller ingestion.ts exports inspectFiles(files:File[],snapshot:Snapshot,onProgress:(job:ImportJob)=>void,signal?:AbortSignal):Promise<{jobs:ImportJob[],assets:SourceAsset[],pages:SourcePage[],duplicates:string[]}> (save original blobs, sequential PDF pages/render previews, honest OCR states). publishImport(s:Snapshot,input:PublishInput):void; exported PublishInput {material:{title,level,edition},unit_title:string,section_type:string,pages:SourcePage[],assets:SourceAsset[],jobs:ImportJob[],entries:Array<{type:'vocabulary'|'target_expression',expression:string,meaning:string,page_id:string,evidence:string}>,lesson?:{actual_date?:string,duration_minutes:number,notes:string}}. publish requires evidence/manual confirmation and stable dedupe; job statuses published/manual_review/cancelled/failed/processing. UI constructs manual entries via line fields, identifies separate PDF/printed indexes, retains raw extraction and offers AI suggestions. Provider API POST /api/structure {kind:'material'|'feedback'|'answer',text,skills?,image?}; GET /api/capabilities => {vision:boolean,structuring:boolean,asr:boolean,tts:boolean}. Missing key returns 503 truthfully. Material adapter returns {material:{title,level,edition},unit_title,section_type,printed_page_number:number|null,entries:[{type,expression,meaning,evidence,confidence}]}. All external OCR requires explicit UI authorization checkbox. ASR POST /api/asr multipart audio + consent=true. Browser speech checkbox warns online browser speech service. UI uses ingestion functions for upload, manual review and publish; no UI hardcoded educational constants.

Only Unit 4 three reference tasks and independently viewed p45/47/49 seed skills allowed. Other V3 units may be reference outline review_status pending; no claim PDFs parsed. Child text responses are evidence pending manual grading, no automatic pass. Seed skill IDs preserve PU1-U4-LIKE-RESP / REQUEST / OFFER-RESP plus banana,bread as source vocabulary after image inspection.
