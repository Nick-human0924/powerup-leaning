# 技术与教研决定

- Next.js15 App Router、React19、TypeScript、Zod、Dexie、pdfjs、Vitest、Playwright。沿用V3信息架构与色系，样式使用模块组件共享CSS；本项目未引入Tailwind，避免对已有视觉做不必要转换。
- 数据优先本机；不制造临时内存服务端数据库。浏览器来源/端口不同档案也不同。未提供账号与云端同步。
- 所有云端密钥在服务端环境变量；教材页/反馈/音频明确授权后才能发往配置的提供商。浏览器WebSpeech由浏览器厂商实现，需要独立说明，不能承诺离线。
- 普通语音转写只提供回答文本；无音素级评分。孩子未配置真实AI时由成人手动核对评分。服务建议永远不是直接成绩。
- 当前缺九份PDF，以V3真实页图建立Unit4基础，其他单元目录pending。PDF文字抽取仅是文字，不等于完整结构化解析；扫描页不得显示成功分析。
- 模型服务使用可替换兼容API适配器；真实API调用未测试，mock覆盖JSON/schema、未知技能拒绝、原话校验、缺凭证与显式授权。
- PDF逐页渲染、限制单文件100MB、检查浏览器配额；推荐每10页分批。页面hash去重只接受同教材版本完全相同像素，不做不可靠相似内容合并。修订由家长核对并保留审计。
- 生成题采用可解释模板；新目标可即时练习，复杂句型模板教研质量需要后续审核。自定义学习目标应填写自然的中文情景，避免把答案直接写到问题里。
- PWA缓存本机访问的应用资源；无权限的HTTP手机环境继续手动模式。正式部署需要HTTPS及站点认证保护，未替用户申请账号或发布公网。
- 教材页图、初始私有JSON与备份在gitignore内。完整迁移需私有目录包，单独clone源码不会携带这些素材。
